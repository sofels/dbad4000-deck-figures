# dbad4000-deck-figures

PNG exports of the figures used in the DBAD 4000 (Advanced Database) Gamma slide decks, hosted here only so Gamma can import them by URL.

- `week_09/` — Week 9, Vector Databases & AI-Era Data Workloads (pgvector): 43 figures; the number in each file name is the card it belongs on (`card01a`–`card01c` are the three introduction slides that follow the title card). The three `wk09_fig_*` files are the Act 1 figures added on 2026-10-26: the embedding workflow, where 384 comes from, and an ordinary table versus a vector table.

The editable SVG masters, alt text and generation scripts live in the course workspace (`04_visuals/week_NN/`), not here. Nothing in this repo is an assessment, key or solution.
