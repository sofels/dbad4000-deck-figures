# dbad4000-deck-figures

PNG exports of the figures used in the DBAD 4000 (Advanced Database) Gamma slide decks, and since 2026-11-07 the CPSY 3000 (Computer Architecture) decks under `cpsy3000/`, hosted here only so Gamma can import them by URL.

- `week_09/` — Week 9, Vector Databases & AI-Era Data Workloads (pgvector): 43 figures; the number in each file name is the card it belongs on (`card01a`–`card01c` are the three introduction slides that follow the title card). The three `wk09_fig_*` files are the Act 1 figures added on 2026-10-26: the embedding workflow, where 384 comes from, and an ordinary table versus a vector table.

- `week_10/` — Week 10, Big Data Processing with Spark: 45 figures plus the shared UNGRADED badge; the number in each file name is the card it belongs on (`card01a`–`card01c` are the three introduction slides that follow card 1.2, added 2026-11-03 with the icebreaker card 1.1; `card16_colab_databricks` replaced `card16_one_machine` the same day; `card24_shuffle_step1`–`3` are one three-frame progression; `card35a`/`35b` both sit after card 35). Cards 34 and 35b embed real Spark UI screenshots from the course-build machine, with the Spark logo masked.

- `week_11/` — Week 11, Lakehouse, Streaming & Enterprise Integration: 27 figures plus the shared UNGRADED badge; the number in each file name is the card it belongs on (`card48_kafka_step1`–`3` and `card49_microbatch_step1`–`3` are two three-frame progressions; `card33_time_travel` follows the Act 3 recap).

- `week_12/` — Week 12, Warehousing, ETL & Analytics (graded GL4 week): 23 figures plus the shared GRADED badge; the number in each file name is the card it belongs on (`card07_star_step1`–`3` and `card23_pipeline_step1`–`4` are two progressions). These are the v2 figures, revised after the Week 12 review on 2026-11-18. `week_12/v3/` holds the title card and the Act 2 divider re-drawn the same day in plain words, so the deck names nothing before it introduces it; the deck uses those two from `v3/` and the rest from `week_12/`.

The editable SVG masters, alt text and generation scripts live in the course workspace (`04_visuals/week_NN/`), not here. Nothing in this repo is an assessment, key or solution.

- `cpsy3000/week_11/` — CPSY 3000 Week 11, Memory Hierarchy: Locality and Caches: 18 figures; the number in each file name is the text card each figure follows (`card01` is the title card). `card18_ripes_cache_map` is an annotated Ripes 2.2.6 screenshot. The editable SVG masters, alt text and generators live in the CPSY 3000 course workspace (`04_visuals/week_11/`). Nothing here is an assessment, key or solution.

- `cpsy3000/week_10/` — CPSY 3000 Week 10, Pipelining and Hazards: one figure, `wk10_card28_flynn` (Flynn's four boxes), used on card 21a of the Week 12 deck since 2026-11-21, where the Flynn segment moved. The editable SVG master and alt text live in the course workspace (`04_visuals/week_10/`). Nothing here is an assessment, key or solution.
