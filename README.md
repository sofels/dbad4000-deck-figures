# dbad4000-deck-figures

PNG exports of the figures used in the DBAD 4000 (Advanced Database) Gamma slide decks, hosted here only so Gamma can import them by URL.

- `week_09/` — Week 9, Vector Databases & AI-Era Data Workloads (pgvector): 37 figures, one per card; the number in each file name is the card it belongs on.

The editable SVG masters, alt text and generation scripts live in the course workspace (`04_visuals/week_NN/`), not here. Nothing in this repo is an assessment, key or solution.
